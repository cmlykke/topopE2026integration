------------------------------------------------------------------------
Any weak PC can DRIVE:

  Controller    — a script (and optionally Hermes/OpenCode) ON THIS PC
  Inference     — HTTP to peer Ollama  http://<peer-100.x>:11434

------------------------------------------------------------------------
2. HARD RULES
------------------------------------------------------------------------
R1. NEVER set User or Machine OLLAMA_HOST permanently to a Tailscale
    100.x address. That made ollama list / local Hermes dial 100.x and
    time out while nothing listened on localhost. Clear both scopes.
R2. NEVER set Hermes model.base_url to THIS PC’s own 100.x.
    ALLOW Hermes base_url = a PEER’s http://100.x:11434/v1 when the
    model runs on that peer (weak-PC orchestrator pattern).
    ALLOW http://127.0.0.1:11434/v1 for local chat-only / worker.
    NEVER http://127.0.0.1:4000/v1 (LiteLLM retired).
R3. Tailscale 100.x belongs in: fleet map, peer curls, the routing
    script, optional Hermes peer base_url. Not in User OLLAMA_HOST.
R4. Expose local Ollama to peers session-only:
      $env:OLLAMA_HOST = "0.0.0.0:11434"
    then ollama serve. Prefer 0.0.0.0 over permanent 100.x.
R5. Do NOT put Ollama or Hermes in Docker. Do NOT install Docker or
    LiteLLM for this workflow.
R6. Do NOT demand 64K Ollama context on an 8 GB machine. Hermes 0.21.x
    requires real ollama_num_ctx >= 64000 FOR TOOLS; that RAM is spent
    on the machine that SERVES the model. Put 64K on a strong peer, or
    skip Hermes tools.
R7. OLLAMA_MODELS on a data drive is nice if you have one. On C:-only
    laptops it is OK to keep models in %USERPROFILE%\.ollama\models.
    If you SET OLLAMA_MODELS to an empty folder, ollama list can go
    blank — clear the env rather than moving 4 GB blindly.
R8. qwen2.5-coder:7b rejects “thinking” → HTTP 400. Interactive:
      /reasoning none --global
R9. Quit Ollama via tray. New PowerShell after User env changes.
R10. Hermes install: Blank Slate (option 3), NOT Nous Portal.
R11. Do not hermes update while rehearsing.
R12. Ollama has no auth — firewall :11434 to Tailscale/trusted only.
R13. Windows curl: curl.exe --noproxy "*" and --data-binary @file.json
    (PowerShell -d $body often Invalid JSON).
R14. OpenCode / OpenClaw / other fat agents have the same 64K-class
    tax if the model is LOCAL. Point them at a peer or do not use them
    as the reason to abandon the script.
R15. One currentToDO at a time. Read whatihavedone before the next.

5. PROCEDURE
------------------------------------------------------------------------

### 5.1 Tailscale
Windows amd64 MSI from https://pkgs.tailscale.com/stable/#windows
Same team tailnet. Verify: tailscale status ; tailscale ip -4
Do not create a private second tailnet.

### 5.2 Optional local worker (expose THIS PC’s model on Tailscale)
Clear User+Machine OLLAMA_HOST.
Install Ollama (default path OK). Pull qwen2.5-coder:7b. Local pong.
Tray Ollama binds 127.0.0.1 only — collaborators cannot use that.
Quit tray Ollama, then:
  chrsetup/start-ollama-worker.ps1
  (session OLLAMA_HOST=0.0.0.0:11434; ollama serve; leave window open)
Firewall: TCP 11434 on Tailscale only (no Ollama auth).
Verify:
  .\verify-ollama-local.ps1
  .\verify-ollama-local.ps1 -Chat
  .\verify-ollama-tailscale.ps1
Pass: last script PASS; netstat shows 0.0.0.0:11434 not only 127.0.0.1.
Give comrades this PC’s tailscale ip -4 + model tag.
They: curl http://<this-100.x>:11434/api/tags
      .\verify-peer-ollama.ps1 -PeerIp <this-100.x> -Chat
Keep context small (~4096). Do not set permanent OLLAMA_HOST=100.x.

### 5.3 Orchestrator smoke (required)
Pick a live peer. Prefer:
  .\verify-peer-ollama.ps1 -PeerIp 100.101.98.59
  .\verify-peer-ollama.ps1 -PeerIp 100.101.98.59 -Chat -Model qwen2.5-coder:7b
Or curl:
  curl.exe --noproxy "*" -s --max-time 15 http://100.101.98.59:11434/api/tags
Then POST /api/chat with model tag from that JSON, stream false,
prompt “Reply with the single word: pong”, --data-binary @file.json
Pass: pong in the response. THIS is the orchestrator bar.

If peer is offline, try the next 200 from tailscale status; do not
block the whole setup on the home desktop.

### 5.4 Fleet map
hostname → Tailscale 100.x → ollama tags. Keep in chrsetup or a
shared file. Script reads this; do not hardcode only in chat memory.

### 5.5 Routing script
Not LiteLLM. Smallest slice first: one function, one peer, write one
file. Expand to docs/workflow-script-design.md phases later.
PowerShell is native on these PCs; bash only if Git Bash is present
and the human wants it.

### 5.6 Optional Hermes (peer brain)
Blank Slate, custom, http://<PEER-100.x>:11434/v1
Model = peer tag. /reasoning none --global for 7b.
Peer must expose 0.0.0.0; for tools peer needs real num_ctx >= 64000.
Local 127.0.0.1:11434 only for chat, tools off, ollama_num_ctx 4096.
Do not set local ollama_num_ctx 65536 on 8 GB.

### 5.7 Do not
Install Docker/LiteLLM; OpenCode as a substitute for the script
unless the human asks for a coding TUI AND it uses a peer baseURL;
move models to an empty OLLAMA_MODELS path; hermes update.
